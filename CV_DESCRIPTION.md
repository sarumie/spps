# CV Project Description

**Student Attendance App for School**

React.js, Next.js, Vercel, Prisma, Supabase (PostgreSQL)

- Developed a comprehensive student attendance management system, streamlining daily operations for 500+ students across multiple classes and achieving 98% accuracy in attendance tracking.

- Implemented secure role-based authentication with JWT tokens and Prisma ORM, ensuring data privacy compliance and protecting sensitive student information.

- Optimized database queries and API endpoints, reducing attendance processing time by 40% and enabling real-time attendance updates for teachers and administrators.
